2. Módulo 1 — Autenticación y Perfiles
5 historias de usuario · Roles: Administrador y Docente
HU-01 Iniciar sesión en el sistema 👤 Admin / Docente
Como usuario registrado (administrador o docente), quiero iniciar sesión con mi nombre de usuario y contraseña, para acceder al sistema de acuerdo con mi rol y permisos asignados.
✅ Criterios de Aceptación
  • El formulario de login solicita únicamente username y password (no correo electrónico).
  • Si las credenciales son correctas y el usuario está activo, el sistema redirige al panel correspondiente (admin o docente).
  • Si las credenciales son incorrectas, el sistema muestra un mensaje de error genérico sin revelar qué campo es incorrecto.
  • Si el usuario está marcado como inactivo, el sistema deniega el acceso y muestra un mensaje indicando que la cuenta está deshabilitada.
  • La sesión persiste hasta que el usuario cierre sesión manualmente o expire.
🔴 Prioridad Alta 📦 Módulo: Autenticación 🔗 RF1.1, RF1.2, RF1.3
HU-02 Cerrar sesión del sistema 👤 Admin / Docente
Como usuario autenticado, quiero cerrar mi sesión de forma segura, para proteger mi cuenta al terminar de usar el sistema.
✅ Criterios de Aceptación
  • Existe un botón o enlace visible de "Cerrar sesión" en el menú de navegación.
  • Al cerrar sesión, el sistema invalida la sesión del servidor y redirige al usuario a la página de login.
  • Tras cerrar sesión, el usuario no puede acceder a páginas protegidas usando el botón "Atrás" del navegador.
🔴 Prioridad Alta 📦 Módulo: Autenticación 🔗 RF1.1
HU-03 Actualizar mi perfil de usuario 👤 Admin / Docente
Como usuario autenticado, quiero poder editar mi nombre, apellido y nombre de usuario, para mantener actualizada mi información personal en el sistema.
✅ Criterios de Aceptación
  • El formulario de perfil muestra los datos actuales del usuario precargados.
  • El sistema valida que el nuevo username no esté ya en uso por otro usuario.
  • Al guardar cambios exitosamente, el sistema muestra un mensaje de confirmación.
  • Si hay errores de validación, se muestran mensajes descriptivos junto al campo correspondiente.
  • El campo nombre y apellido son obligatorios con máximo 100 caracteres cada uno.
🟡 Prioridad Media 📦 Módulo: Autenticación 🔗 RF1.4
HU-04 Cambiar mi contraseña de acceso 👤 Admin / Docente
Como usuario autenticado, quiero poder cambiar mi contraseña de forma segura, para proteger mi cuenta si creo que ha sido comprometida.
✅ Criterios de Aceptación
  • El formulario solicita la contraseña actual, la nueva contraseña y su confirmación.
  • Si la contraseña actual no coincide, el sistema muestra un error sin actualizar nada.
  • La nueva contraseña debe tener mínimo 8 caracteres.
  • La nueva contraseña y su confirmación deben ser idénticas.
  • La contraseña se almacena encriptada con bcrypt (nunca en texto plano).
  • Al cambiar con éxito, el sistema muestra un mensaje de confirmación.
🔴 Prioridad Alta 📦 Módulo: Autenticación 🔗 RF1.5, RNF1.1
HU-05 Bloquear acceso a usuarios inactivos 🛡️ Administrador
Como administrador, quiero que el sistema bloquee automáticamente el acceso a usuarios marcados como inactivos, para revocar permisos de forma inmediata sin eliminar sus datos.
✅ Criterios de Aceptación
  • El sistema verifica el estado activo del usuario en cada petición HTTP mediante middleware.
  • Si un usuario con sesión activa es marcado como inactivo, la siguiente petición cierra su sesión y lo redirige al login.
  • El usuario inactivo no puede iniciar sesión aunque ingrese credenciales correctas.
  • Al reactivar el usuario, puede volver a iniciar sesión normalmente.
🔴 Prioridad Alta 📦 Módulo: Autenticación 🔗 RF1.2, RNF1.5

3. Módulo 2 — Estructura Académica
6 historias de usuario · Rol: Administrador
HU-06 Gestionar Niveles Educativos 🛡️ Administrador
Como administrador, quiero crear, editar y eliminar niveles educativos (Inicial, Primaria, Secundaria), para definir la estructura base de la institución sobre la cual se organizan los grados y cursos.
✅ Criterios de Aceptación
  • El administrador puede crear un nivel ingresando únicamente su nombre.
  • El administrador puede editar el nombre de un nivel existente.
  • El sistema impide eliminar un nivel si tiene grados asociados, mostrando un mensaje de advertencia.
  • Los niveles se listan en orden y son visibles en el módulo de grados para su selección.
🔴 Prioridad Alta 📦 Módulo: Estructura Académica 🔗 RF2.1
HU-07 Gestionar Grados 🛡️ Administrador
Como administrador, quiero registrar y gestionar los grados escolares vinculados a un nivel, para organizar correctamente la estructura curricular de la institución.
✅ Criterios de Aceptación
  • Al crear un grado, es obligatorio seleccionar el nivel al que pertenece.
  • El administrador puede editar el nombre y nivel de un grado existente.
  • El sistema impide eliminar grados que tengan secciones o asignaciones docentes activas.
  • Los grados aparecen correctamente asociados a su nivel en el mapa académico.
🔴 Prioridad Alta 📦 Módulo: Estructura Académica 🔗 RF2.2
HU-08 Gestionar Secciones 🛡️ Administrador
Como administrador, quiero crear y administrar secciones (A, B, C, Única) para subdividir los grados, para poder asignar docentes y grupos de alumnos específicos dentro de un mismo grado.
✅ Criterios de Aceptación
  • El administrador puede crear secciones con un nombre identificativo (letras o palabras).
  • Las secciones se listan y están disponibles en los formularios de asignación docente.
  • El sistema impide eliminar secciones que tengan asignaciones activas.
🔴 Prioridad Alta 📦 Módulo: Estructura Académica 🔗 RF2.3
HU-09 Gestionar Cursos / Materias 🛡️ Administrador
Como administrador, quiero crear, editar y eliminar cursos o materias de la currícula, para que los docentes puedan ser asignados a las materias que imparten.
✅ Criterios de Aceptación
  • El administrador puede crear un curso ingresando su nombre.
  • Los cursos están disponibles en los formularios de asignación docente y en el filtro de archivos.
  • El sistema impide eliminar un curso que tenga asignaciones docentes o archivos asociados.
🔴 Prioridad Alta 📦 Módulo: Estructura Académica 🔗 RF2.4
HU-10 Gestionar Años Lectivos 🛡️ Administrador
Como administrador, quiero registrar y activar años lectivos, para que las operaciones de carga y consulta de archivos estén siempre referenciadas al año académico correcto.
✅ Criterios de Aceptación
  • El administrador puede registrar un año lectivo especificando el año (Ej: 2026).
  • Solo puede haber un año lectivo activo a la vez; activar uno desactiva al anterior.
  • El año lectivo activo es el que aparece por defecto en los filtros y formularios de archivos.
  • El sistema muestra claramente cuál es el año lectivo actualmente activo.
🔴 Prioridad Alta 📦 Módulo: Estructura Académica 🔗 RF2.5
HU-11 Ver el Mapa Académico institucional 🛡️ Administrador
Como administrador, quiero ver una vista jerárquica de Niveles → Grados → Cursos con sus docentes asignados, para tener una visión consolidada e inmediata de toda la estructura académica de la institución.
✅ Criterios de Aceptación
  • El dashboard muestra todos los niveles activos con sus grados anidados.
  • Cada grado muestra los cursos asignados y el nombre del docente responsable.
  • La vista es navegable y distingue visualmente cada nivel jerárquico.
  • El mapa refleja los datos en tiempo real conforme se realizan cambios en asignaciones.
🟡 Prioridad Media 📦 Módulo: Estructura Académica 🔗 RF2.6

4. Módulo 3 — Gestión de Docentes
4 historias de usuario · Rol: Administrador
HU-12 Registrar un nuevo docente 🛡️ Administrador
Como administrador, quiero registrar nuevos profesores en el sistema, para que puedan acceder a su portafolio y gestionar sus materiales educativos.
✅ Criterios de Aceptación
  • El formulario solicita: nombre, apellido, username y contraseña.
  • El correo electrónico se genera automáticamente con el formato {username}@docente.local.
  • El username debe ser único en todo el sistema.
  • La contraseña se almacena encriptada con bcrypt.
  • El docente se crea con estado activo por defecto y con el rol docente.
  • Al crear exitosamente, el sistema muestra un mensaje de confirmación y redirige al listado.
🔴 Prioridad Alta 📦 Módulo: Docentes 🔗 RF3.1
HU-13 Activar o desactivar un docente 🛡️ Administrador
Como administrador, quiero habilitar o deshabilitar el acceso de un docente con un solo clic, para gestionar permisos de forma ágil sin perder el historial de archivos del docente.
✅ Criterios de Aceptación
  • En el listado de docentes aparece un botón toggle (activo/inactivo) por cada registro.
  • Al desactivar, el campo activo cambia a false y el docente no puede iniciar sesión.
  • Si el docente tiene sesión abierta, la siguiente petición es bloqueada por el middleware.
  • El docente NO es eliminado físicamente, preservando todos sus archivos subidos.
  • Al reactivar, el docente puede iniciar sesión nuevamente de forma normal.
🔴 Prioridad Alta 📦 Módulo: Docentes 🔗 RF3.2, RNF4.3
HU-14 Asignar cursos y aulas a un docente 🛡️ Administrador
Como administrador, quiero vincular a cada docente con una o más combinaciones de Curso + Grado + Sección, para que el docente solo vea sus materias asignadas al gestionar su portafolio.
✅ Criterios de Aceptación
  • El formulario permite seleccionar múltiples combinaciones [Curso + Grado + Sección] para un docente.
  • Cada combinación representa una clase activa a cargo del docente.
  • Las asignaciones se guardan en la tabla docente_asignaciones con integridad referencial.
  • El docente solo puede subir archivos a sus asignaciones activas.
  • Las asignaciones aparecen correctamente en el selector de asignación del portafolio docente.
🔴 Prioridad Alta 📦 Módulo: Docentes 🔗 RF3.3
HU-15 Editar datos y asignaciones del docente 🛡️ Administrador
Como administrador, quiero actualizar el perfil y las asignaciones de un docente en un único formulario, para mantener los datos y carga horaria siempre sincronizados.
✅ Criterios de Aceptación
  • El formulario de edición precarga los datos actuales del docente y sus asignaciones vigentes.
  • Al guardar, el sistema elimina todas las asignaciones previas y crea únicamente las nuevas seleccionadas.
  • Si no se selecciona ninguna asignación, el docente queda sin cursos asignados (sin error).
  • Los cambios en el nombre o username se validan igual que en el registro (username único).
  • El sistema muestra confirmación de éxito al guardar.
🟡 Prioridad Media 📦 Módulo: Docentes 🔗 RF3.4

5. Módulo 4 — Portafolio de Archivos
9 historias de usuario · Roles: Docente y Administrador
HU-16 Subir un archivo al portafolio 🧑‍🏫 Docente
Como docente, quiero subir archivos educativos asociados a mis asignaciones y al bimestre correspondiente, para construir mi portafolio digital y cumplir con la entrega de materiales académicos.
✅ Criterios de Aceptación
  • El formulario permite seleccionar una de mis asignaciones activas (Curso + Grado + Sección).
  • El docente debe seleccionar el bimestre (I, II, III o IV Bimestre).
  • El campo descripción es opcional.
  • Se acepta cualquier tipo de archivo (PDF, Word, Excel, imagen, etc.).
  • El año se asocia automáticamente al año actual en curso.
  • El archivo se guarda en storage/app/public/docentes/{id}/ con un nombre único.
  • Al subir exitosamente, el sistema redirige al listado con un mensaje de confirmación.
🔴 Prioridad Alta 📦 Módulo: Portafolio 🔗 RF4.1, RNF4.4
HU-17 Buscar y filtrar mis archivos 🧑‍🏫 Docente
Como docente, quiero filtrar mis archivos por año, bimestre, curso y fechas, para encontrar rápidamente cualquier documento que haya subido anteriormente.
✅ Criterios de Aceptación
  • El listado muestra los archivos paginados (15 por página) ordenados por bimestre.
  • Se puede filtrar por: año lectivo, bimestre, curso (por ID o nombre), fecha desde y fecha hasta.
  • Se puede buscar por término libre en nombre del archivo o descripción.
  • Los filtros son acumulativos y persisten en la URL para poder compartirlos.
  • Si no hay resultados, se muestra un mensaje amigable indicándolo.
🔴 Prioridad Alta 📦 Módulo: Portafolio 🔗 RF4.2, RNF3.1
HU-18 Descargar mis archivos 🧑‍🏫 Docente
Como docente, quiero descargar mis archivos con su nombre original, para obtener una copia local cuando la necesite.
✅ Criterios de Aceptación
  • El botón de descarga está disponible en el listado de mis archivos.
  • El archivo descargado conserva su nombre original (no el nombre interno del sistema).
  • El sistema verifica que el archivo pertenece al docente autenticado antes de servirlo.
  • Si el archivo físico no existe en el servidor, el sistema muestra un mensaje de error descriptivo.
  • Un docente no puede descargar archivos de otros docentes (error 403).
🔴 Prioridad Alta 📦 Módulo: Portafolio 🔗 RF4.3, RNF1.2
HU-19 Previsualizar un archivo en el navegador 🧑‍🏫 Docente / 🛡️ Admin
Como docente o administrador, quiero previsualizar archivos directamente en el navegador sin tener que descargarlos, para revisar el contenido de forma rápida y eficiente.
✅ Criterios de Aceptación
  • Existe un botón "Ver/Previsualizar" junto a cada archivo en el listado.
  • El archivo se abre en línea (stream inline) en el navegador (sin forzar descarga).
  • Para PDFs, el navegador los renderiza directamente; para otros tipos, abre el visor disponible.
  • El sistema genera una URL firmada temporal (10 min) para compatibilidad con Google Docs Viewer.
  • La URL firmada expira automáticamente después de 10 minutos para mayor seguridad.
🟡 Prioridad Media 📦 Módulo: Portafolio 🔗 RF4.4, RNF1.3
HU-20 Mover un archivo a la papelera 🧑‍🏫 Docente
Como docente, quiero mover archivos equivocados o innecesarios a la papelera, para mantener mi portafolio organizado sin eliminarlos permanentemente de inmediato.
✅ Criterios de Aceptación
  • El botón "Eliminar / Mover a papelera" está visible en el listado de archivos.
  • El archivo se marca con eliminación lógica (deleted_at), no se borra físicamente del disco.
  • El archivo desaparece del listado principal pero aparece en la sección Papelera.
  • El sistema muestra un mensaje de confirmación indicando que el archivo fue movido a la papelera.
  • El docente solo puede mover a la papelera sus propios archivos.
🟡 Prioridad Media 📦 Módulo: Portafolio 🔗 RF4.5, RNF4.2
HU-21 Restaurar un archivo desde la papelera 🧑‍🏫 Docente
Como docente, quiero restaurar archivos que envié accidentalmente a la papelera, para recuperarlos sin perder el trabajo ya realizado.
✅ Criterios de Aceptación
  • La sección Papelera muestra todos mis archivos eliminados con su fecha de borrado.
  • El botón "Restaurar" está disponible para cada archivo en la papelera.
  • Al restaurar, el campo deleted_at se limpia y el archivo vuelve al listado principal.
  • El sistema muestra un mensaje de confirmación al restaurar exitosamente.
  • Solo el docente propietario puede restaurar sus archivos.
🟡 Prioridad Media 📦 Módulo: Portafolio 🔗 RF4.5, RNF4.2
HU-22 Eliminar un archivo definitivamente 🧑‍🏫 Docente
Como docente, quiero eliminar permanentemente archivos de mi papelera, para liberar espacio de almacenamiento y limpiar documentos que ya no necesito.
✅ Criterios de Aceptación
  • El botón "Eliminar definitivamente" solo está disponible en la vista de Papelera.
  • El sistema elimina tanto el registro de la base de datos como el archivo físico del disco.
  • La acción es irreversible: el archivo no puede recuperarse una vez eliminado definitivamente.
  • Solo el docente propietario puede eliminar definitivamente sus archivos.
  • El sistema muestra un mensaje de confirmación tras la eliminación.
🟢 Prioridad Baja 📦 Módulo: Portafolio 🔗 RF4.5
HU-23 Supervisar archivos de todos los docentes 🛡️ Administrador
Como administrador, quiero ver y buscar todos los archivos subidos por todos los docentes en un único panel, para supervisar el cumplimiento de entrega de materiales educativos.
✅ Criterios de Aceptación
  • El panel administrativo lista todos los archivos de todos los docentes con paginación.
  • Se puede filtrar por: docente, año lectivo, bimestre, curso, grado, sección, nivel y rango de fechas.
  • Cada fila muestra: nombre del archivo, docente, curso, grado, sección, bimestre y fecha de subida.
  • El administrador puede descargar o previsualizar cualquier archivo del sistema.
  • La búsqueda es eficiente gracias a los filtros combinados.
🔴 Prioridad Alta 📦 Módulo: Portafolio 🔗 RF4.6, RF4.7, RF4.8
HU-24 Gestionar la papelera administrativa 🛡️ Administrador
Como administrador, quiero ver todos los archivos en papelera de todos los docentes y poder restaurarlos o eliminarlos definitivamente, para tener control total sobre el almacenamiento de la institución.
✅ Criterios de Aceptación
  • La papelera administrativa muestra todos los archivos eliminados de todos los docentes.
  • Se muestra el nombre del docente propietario, fecha de eliminación y datos del archivo.
  • El administrador puede restaurar cualquier archivo (independientemente del docente).
  • El administrador puede eliminar permanentemente archivos, borrando el registro y el archivo físico.
  • Los resultados están paginados para evitar problemas de rendimiento.
🟡 Prioridad Media 📦 Módulo: Portafolio 🔗 RF4.9

6. Módulo 5 — Configuración Institucional
2 historias de usuario · Rol: Administrador
HU-25 Editar los datos de la institución 🛡️ Administrador
Como administrador, quiero actualizar la información de contacto e identificación de la institución, para que los datos mostrados en el sistema estén siempre vigentes y correctos.
✅ Criterios de Aceptación
  • El formulario permite editar: nombre, dirección, teléfono, correo electrónico y sitio web.
  • Solo el campo "nombre" es obligatorio; los demás son opcionales.
  • El correo debe tener formato de email válido; el sitio web debe ser una URL válida.
  • Los datos se guardan en config/institucion.json para lectura eficiente.
  • Los cambios se reflejan inmediatamente en los layouts de administrador y docente.
  • El sistema muestra un mensaje de éxito al guardar correctamente.
🟢 Prioridad Baja 📦 Módulo: Configuración 🔗 RF5.1, RF5.3
HU-26 Actualizar el logo institucional 🛡️ Administrador
Como administrador, quiero subir o actualizar el logo de la institución, para que la imagen corporativa de la escuela esté presente en toda la interfaz del sistema.
✅ Criterios de Aceptación
  • El formulario permite subir un archivo de imagen en formato .jpg, .png o .webp.
  • El tamaño máximo del logo es de 2 MB.
  • Si no se sube un nuevo logo, el logo actual se mantiene sin cambios.
  • El logo se guarda en public/images/ y su ruta se registra en el JSON de configuración.
  • El nuevo logo se muestra inmediatamente en el header de los paneles de administración y docente.
🟢 Prioridad Baja 📦 Módulo: Configuración 🔗 RF5.2

7. Módulo 6 — Reportes de Cumplimiento
2 historias de usuario · Rol: Administrador
HU-27 Generar reporte de cumplimiento docente 🛡️ Administrador
Como administrador, quiero generar reportes de cumplimiento de entrega de documentos por docente y bimestre, para identificar qué profesores han cumplido con sus obligaciones académicas y cuáles tienen documentos pendientes.
✅ Criterios de Aceptación
  • El reporte puede generarse filtrando por año lectivo y bimestre (I, II, III, IV o Todos).
  • Por cada docente activo se muestra: total de asignaciones, completadas, pendientes y % de cumplimiento.
  • Si se selecciona "Todos los Bimestres", el reporte desglosa el cumplimiento por cada uno de los 4 bimestres.
  • El porcentaje global de cumplimiento institucional se muestra como indicador principal.
  • Los docentes sin asignaciones activas muestran cumplimiento del 100%.
  • Si no se hace clic en "Generar", el reporte aparece vacío (no muestra datos por defecto).
🔴 Prioridad Alta 📦 Módulo: Reportes 🔗 RF6.1, RF6.2
HU-28 Exportar el reporte en CSV y Word 🛡️ Administrador
Como administrador, quiero exportar el reporte de cumplimiento en formato CSV o Word, para compartirlo con directivos, archivarlo o importarlo en otras herramientas de análisis.
✅ Criterios de Aceptación
  • El botón "Exportar CSV" descarga un archivo .csv con codificación UTF-8 BOM (compatible con Excel).
  • El botón "Exportar Word" descarga un archivo .doc con el reporte formateado.
  • Ambos archivos incluyen: cabecera institucional, nombre del reporte, resumen global y tabla por docente.
  • El Word incluye estilos visuales (colores, tipografía) y secciones separadas por bimestre si aplica.
