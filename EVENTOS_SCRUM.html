3.2.1.5. Daily Scrum

Durante el desarrollo del proyecto se realizaron reuniones periódicas de seguimiento con la finalidad de monitorear el avance de las actividades planificadas en cada Sprint. Estas reuniones permitieron verificar el cumplimiento de las tareas asignadas, identificar dificultades durante el desarrollo y establecer acciones correctivas para garantizar el cumplimiento de los objetivos definidos.

En cada sesión de seguimiento se revisaron tres aspectos fundamentales:

  • Las actividades completadas desde la reunión anterior.
  • Las actividades que se desarrollarían posteriormente.
  • Los impedimentos o dificultades que podrían afectar el avance del proyecto.

3.2.1.6. Sprint Review

Al finalizar cada Sprint se realizó una revisión de los entregables desarrollados con el propósito de verificar el cumplimiento de los objetivos establecidos y validar las funcionalidades implementadas. Durante estas revisiones se evaluó el estado de las historias de usuario seleccionadas para cada iteración, verificando que cumplieran con los criterios de aceptación definidos previamente.

La revisión permitió identificar avances, validar funcionalidades desarrolladas y determinar las actividades pendientes para los siguientes Sprints.

3.2.1.7. Sprint Retrospective

Posterior a la revisión de cada Sprint y previo a la siguiente planificación, el equipo de desarrollo llevó a cabo una retrospectiva. Esta reunión tuvo como finalidad evaluar y reflexionar sobre el proceso de trabajo empleado durante la iteración recién concluida, analizando aspectos relacionados con las personas, las relaciones, los procesos y las herramientas utilizadas.

Durante esta evaluación se identificaron las prácticas que funcionaron adecuadamente y las áreas que requerían optimización, permitiendo así establecer un plan de acción con propuestas de mejora continua para incrementar la calidad y eficiencia en los Sprints posteriores.
