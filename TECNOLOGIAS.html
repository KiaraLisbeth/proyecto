Cuadro de Tecnologías y Herramientas Utilizadas

Categoría Tecnología / Herramienta Descripción y Uso en el Proyecto
Backend (Lógica de Servidor) PHP Lenguaje de programación principal del lado del servidor utilizado para desarrollar toda la lógica de negocio.
Laravel Framework Framework PHP de código abierto que proporciona la estructura base del sistema (Patrón MVC), ruteo seguro y autenticación.
Frontend (Interfaz de Usuario) Laravel Blade Motor de plantillas nativo de Laravel utilizado para generar las vistas dinámicas en HTML (interfaces de docentes y administradores).
Tailwind CSS (v4) Framework CSS de utilidad utilizado para el diseño moderno, la estilización de componentes y la adaptabilidad móvil (Responsive Design).
Vite & JavaScript Vite actúa como empaquetador ultrarrápido para procesar los estilos y scripts modernos en JavaScript.
Base de Datos MySQL Sistema Gestor de Base de Datos Relacional (RDBMS) utilizado para el almacenamiento persistente de usuarios, archivos, grados y secciones.
Entorno y Dependencias Composer & NPM Gestores de paquetes utilizados para administrar e instalar las dependencias de PHP (Composer) y de JavaScript (NPM).
Git Sistema de control de versiones distribuido utilizado para llevar el registro de cambios en el código fuente del proyecto.
