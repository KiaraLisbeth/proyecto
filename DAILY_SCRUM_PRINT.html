3.2.3.5 Daily Scrum

Durante el desarrollo del proyecto se realizaron reuniones periódicas de seguimiento con la finalidad de monitorear el avance de las actividades planificadas en cada Sprint. Estas reuniones permitieron verificar el cumplimiento de las tareas asignadas, identificar dificultades durante el desarrollo y establecer acciones correctivas para garantizar el cumplimiento de los objetivos definidos.

En cada sesión de seguimiento se revisaron tres aspectos fundamentales:

  • Las actividades completadas desde la reunión anterior.
  • Las actividades que se desarrollarían posteriormente.
  • Los impedimentos o dificultades que podrían afectar el avance del proyecto.

Asimismo, se realizó un control continuo del progreso de las historias de usuario incluidas en cada Sprint, verificando su estado de desarrollo y el cumplimiento de los criterios de aceptación establecidos en el Product Backlog.

La aplicación de reuniones de seguimiento permitió mantener una adecuada organización del trabajo, facilitar la resolución de problemas y asegurar el desarrollo incremental del sistema web de gestión de archivos académicos y reportes de cumplimiento para la I.E.P. Esther Carson.
