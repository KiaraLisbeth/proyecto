Parte 3 · Metodología SCRUM
03 / 08
🔄 SCRUM

¿Por qué usé SCRUM?

Para este proyecto utilicé la metodología ágil SCRUM, porque permite desarrollar el sistema en iteraciones cortas llamadas Sprints, lo que me ayudó a entregar funcionalidades completas y funcionales en cada etapa del proyecto.

Trabajé con 3 Sprints:
  • ▸
    Sprint 1 — Autenticación de usuarios y gestión de Año Lectivo
  • ▸
    Sprint 2 — Gestión de Docentes y subida de Archivos
  • ▸
    Sprint 3 — Módulo de Reportes PDF y Secciones/Grados
Cada Sprint tuvo su Sprint Planning para definir tareas, y su Sprint Review para validar el avance.
💡 Si te preguntan: "¿qué era el Product Backlog?" → Di: "La lista priorizada de todos los módulos del sistema."
Parte 4 · Base de Datos
04 / 08
🗄️ Base de Datos

Diseño de la Base de Datos

La base de datos está diseñada en MySQL con 8 tablas principales relacionadas entre sí.

Las entidades clave son: users —que almacena administradores y docentes—, docentes, archivos, años_lectivos, grados, secciones, cursos y año_grado_seccion.
  • ▸
    Cada docente se vincula a un user del sistema
  • ▸
    Los archivos se asocian a un docente y a un año lectivo
  • ▸
    Las secciones pertenecen a grados dentro de un año lectivo
  • ▸
    Hay más de 20 registros de prueba en cada tabla (seeders)
Utilicé Eloquent ORM de Laravel para manejar las relaciones entre modelos, lo que hace el código más limpio y mantenible.
💡 Si te preguntan por la relación: "¿Qué relación tiene docente con archivo?" → "Es uno a muchos: un docente puede subir muchos archivos."

Bonus · Preguntas Frecuentes del Tribunal
❓ Q&A

Respuestas Rápidas para el Tribunal

  • Q
    ¿Qué es SCRUM?
    Es una metodología ágil de trabajo en iteraciones cortas llamadas Sprints, con roles definidos: Product Owner, Scrum Master y el equipo de desarrollo.
  • Q
    ¿Cuál fue tu Sprint más difícil?
    El Sprint 2, donde implementé la subida de archivos con validación de tipos y el CRUD de docentes con sus relaciones en la base de datos.
  • Q
    ¿Cómo garantizas la seguridad?
    Con autenticación Laravel Auth, protección CSRF en formularios, validaciones en Request y control de acceso por roles (middleware).
  • Q
    ¿Qué es Eloquent ORM?
    Es el sistema de Laravel para interactuar con la base de datos usando objetos PHP en lugar de SQL puro, haciendo el código más limpio.
  • Q
    ¿Qué mejorarías del sistema?
    Agregaría notificaciones por correo cuando un docente sube un archivo, y una vista de estadísticas gráficas para el administrador.
